# Portfolio Website 🌐

My personal portfolio website built from scratch using HTML, CSS, and JavaScript — showcasing my projects, skills, and background as a student developer.

🔗 **Live Site:** https://noorfatima0079.github.io/portfolio-website/

## ✨ Features
- Typing animation on the hero heading
- Smooth scroll navigation
- Scroll-reveal animations for each section
- Active nav link highlighting based on scroll position
- Dark/Light mode toggle
- Fully responsive design (mobile-friendly)

## 🛠️ Technologies Used
- HTML5
- CSS3 (custom animations, responsive design)
- JavaScript (DOM manipulation, event listeners, Intersection Observer API)

## 📁 Project Structure
- `index.html` – Main page structure
- `style.css` – All styling, animations, and responsive design
- `script.js` – Typing effect, smooth scroll, scroll-reveal, theme toggle, active nav highlighting

## ▶️ How to Run Locally
1. Clone this repository
2. Open `index.html` in your browser (or use a Live Server extension in VS Code)
